# POM Plugin Base documentation

This directory contains the guides shipped with the base plugin. The POM can
show these files in its plugin documentation view after the plugin is
installed.

- [Development guide](guia-desenvolvimento.md)
- [Shared workspace guide](guia-workspace.md)

The file list is registered by `documentation` in `ui/manifest.json` and the
Markdown files are embedded as plugin assets during the native build.
